# Workspace Rules

## Cloudflare Safety & Permission Protocol
- **MANDATORY**: Before making ANY changes to Cloudflare (including deploying or updating Workers, modifying KV namespaces, creating or altering Cron Triggers, changing Environment Variables/Secrets, or deleting resources), you MUST explicitly ask the user for permission.
- Detail the exact changes you plan to make and wait for the user's clear approval before proceeding with any deployment or modification command (via CLI, API, or MCP tools).
